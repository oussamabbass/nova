Application de **stories / statuts** (style Snapchat) : photo, vidéo et texte, visibles 24 h.

## Fonctionnalités

- Stories **photo**, **vidéo** et **texte**
- Anneaux de statuts (vus / non vus)
- Caméra avant / arrière
- Viewer plein écran + barre de progression
- Expiration automatique après **24 heures**
- Interface mobile-first
- Pages `/privacy` et `/terms`
